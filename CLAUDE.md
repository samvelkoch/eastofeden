# Правила для этого репозитория

- Это дневник чтения Samvel. Главное правило: **никаких спойлеров**. На сайте только то, что прочитано до границы из `data.json → current`. Никаких намёков вроде «этот персонаж ещё сыграет роль».
- Каин и Авель: только параллели, видимые в прочитанном тексте, как возможные прочтения с пометкой «параллель — не прогноз».
- Факты (история, реалии) и трактовки всегда разделены (`kind: fact | reading`).
- Дизайн монохромный (ч/б/серый), без цвета. Исключение по просьбе Samvel: читательские темы «Сепия» и «Ночная сепия» (тот же монохром, только тёплый тон). Мобильный экран рядом с Kindle — основной сценарий.
- Тексты на русском, коротко.
