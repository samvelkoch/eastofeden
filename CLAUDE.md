# Правила для этого репозитория

- Это дневник чтения Samvel. Главное правило: **никаких спойлеров**. На сайте только то, что прочитано до границы из `data.json → current`. Никаких намёков вроде «этот персонаж ещё сыграет роль».
- Каин и Авель: только параллели, видимые в прочитанном тексте, как возможные прочтения с пометкой «параллель — не прогноз».
- Факты (история, реалии) и трактовки всегда разделены (`kind: fact | reading`).
- Дизайн монохромный (ч/б/серый), без цвета. Исключение по просьбе Samvel: читательские темы «Сепия» и «Ночная сепия» (тот же монохром, только тёплый тон). Мобильный экран рядом с Kindle — основной сценарий.
- Тексты на русском, коротко.
- «Дневник романа» (`data.json → journal.entries`, вкладка #journal): письма Стейнбека Ковичи 1951 года. Только записи о прочитанных главах; поле `ch` обязательно, иначе запись считается «о книге в целом». Стейнбек в письмах часто забегает вперёд — такие фразы не брать. Цитаты в нашем переводе на русский, без полного перевода.
- Режим «мой прогресс» (`app.js → gate`, выбор в шапке, `localStorage eoe-read`): для читателей, что дальше автора не ушли, сайт прячет всё, что привязано к главам > N. Поэтому у КАЖДОГО нового элемента (цитата, событие, смысл, пункт мира/карты, запись дневника, `ev` героя) должна быть корректная отметка главы (`ch`/`src`/`where`/`chs`), а упоминания «гл. N» в тексте не должны вести дальше самой главы элемента. Сводные тексты без глав (`short`, `bio`, `storylines.beats/now`, `cast[i][1]`, `debates`, `questions`, блок «Семьи» в index.html) для чужого прогресса скрываются целиком.
